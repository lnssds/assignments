## 第一部分：基础几何变换

### 运行方式

```
python 作业1.1.py
```

运行后会自动打开 Gradio 交互界面，支持实时调整以下参数：
- **Scale**：缩放比例，范围 0.1× ~ 2.0×，小于 1 为缩小，大于 1 为放大
- **Rotation**：旋转角度，范围 -180° ~ 180°，正值为逆时针旋转
- **Translation X/Y**：水平和垂直方向平移量，范围 -300 ~ 300 像素
- **Horizontal Flip**：水平翻转开关，勾选后图像沿垂直轴镜像

### 实现原理

基础几何变换的核心是仿射变换矩阵的构造与复合。由于 OpenCV 的 `warpAffine` 默认以图像左上角 (0,0) 为变换中心，直接旋转或缩放会导致图像偏离中心位置，因此需要通过矩阵复合将变换中心移到图像中心。

具体来说，设图像宽高为 W、H，中心坐标为 (cx, cy) = (W/2, H/2)，完整的变换矩阵由以下步骤复合而成：

1. **平移到原点**：将图像中心平移到坐标原点，变换矩阵为
   ```
   T1 = [[1, 0, -cx],
         [0, 1, -cy]]
   ```
2. **缩放变换**：以原点为中心进行缩放
   ```
   S = [[sx, 0, 0],
        [0, sy, 0]]
   ```
3. **旋转变换**：以原点为中心旋转 θ 角（需转换为弧度）
   ```
   R = [[cosθ, -sinθ, 0],
        [sinθ,  cosθ, 0]]
   ```
4. **平移回中心并叠加偏移**：将图像移回原中心位置，并加上用户指定的平移量 (tx, ty)
   ```
   T2 = [[1, 0, cx + tx],
         [0, 1, cy + ty]]
   ```
5. **水平翻转**（可选）：若勾选翻转，在最后乘以翻转矩阵
   ```
   F = [[-1, 0, W],
        [ 0, 1, 0]]
   ```

最终变换矩阵 M = T2 × R × S × T1（若翻转则再乘 F）。变换后超出图像边界的区域用白色 (255,255,255) 填充，避免出现黑边。

## 第二部分：点引导图像变形（MLS）

### 运行方式

```
python 作业1.2.py
```

### 交互操作

1. 点击 **Upload** 上传一张图像
2. 在图像上交替点击选取控制点：第一个点为源点（蓝色），第二个点为对应的目标点（红色），以此类推。源点和目标点之间用绿色箭头连接，表示该点的位移方向
3. 至少放置一对控制点后，点击 **Run Warping** 执行变形
4. 若效果不满意，点击 **Clear Points** 清空所有控制点重新选择

### 算法原理

MLS 变形的核心思想是：对于图像中的每个像素，根据控制点集计算一个加权的局部仿射变换，使得该像素在变换后的位置由所有控制点共同决定，且距离越近的控制点权重越大。

设源控制点集为 {p_i}，目标控制点集为 {q_i}，对于图像中任意一点 v：

1. **计算加权质心**：
   ```
   p* = Σ w_i p_i / Σ w_i
   q* = Σ w_i q_i / Σ w_i
   ```
   其中权重 w_i = 1 / |p_i - v|²α，本实现取 α = 1（反距离平方权重）。

2. **计算局部坐标**：
   ```
   p̂_i = p_i - p*
   q̂_i = q_i - q*
   ```

3. **求解仿射变换**：通过最小化加权最小二乘问题
   ```
   min Σ w_i |M p̂_i - q̂_i|²
   ```
   得到该像素处的局部仿射变换矩阵 M。

4. **计算变形后位置**：f(v) = M(v - p*) + q*

对所有像素计算变形后坐标后，使用 `cv2.remap` 函数进行双线性插值重采样，得到最终变形图像。使用反向映射（即从目标图像坐标反查源图像坐标）保证输出图像每个像素都有值，避免出现空洞。

### 实现细节

- 权重计算时添加一个小的 epsilon（1e-8）防止除零
- 变形前先将图像坐标归一化到 [-1, 1] 范围，提高数值稳定性
- `cv2.remap` 使用 `INTER_LINEAR` 双线性插值，边界模式为 `BORDER_CONSTANT`，白色填充
- 控制点数量至少为 2 对（1 对点只能做平移，无法产生变形效果）
